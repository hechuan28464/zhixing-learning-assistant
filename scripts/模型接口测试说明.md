# 本地模型接口检查

接口已配置在项目根目录的 `.env.local`，该文件由 `.gitignore` 排除，不应进入代码、文档或提交包。可公开配置字段见 [配置模板](F:/实训伴学4/.env.example)。环境变量优先于本地文件。

2026-11-02 实测：模型列表接口返回25个模型；使用 `qwen3.8-flash` 请求关闭思考后，简短生成返回 `OK`。这是连通性检查，不是教学能力、工具调用或并发性能评测。

只查询模型列表：

```powershell
python F:\实训伴学4\scripts\check_model_api.py
```

发送一次短提示进行生成检查，可能产生少量接口用量：

```powershell
python F:\实训伴学4\scripts\check_model_api.py --smoke
```

可用 `--model` 临时指定模型，`--max-tokens` 调整小额输出预算。`LLM_ENABLE_THINKING=false` 会添加本次实测可用的可选请求字段；其他模型是否支持该字段需分别检查。脚本只用Python标准库，日志不打印密钥，拒绝自动HTTP重定向。

后续开发需另测流式响应、工具调用、结构化输出、取消、超时和预算。当前并未创建完整教育Agent应用。
